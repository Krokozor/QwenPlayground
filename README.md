# QwenPlayground

AI-компаньон для разработки: автономный агент, который работает над вашим проектом, модифицирует собственный код и пересобирает себя.

## Возможности

- **Агентный цикл** — LLM-модель (OpenAI-совместимый API, например llama.cpp) с инструментами: файлы, shell, Roslyn, браузер, память
- **Самомодификация** — `rebuild_self`: агент правит свой код, пересобирает и рестартует себя
- **Долговременная память** — факты, ассоциативный реколл, heartbeat-процессы, слои L1–L3
- **Мультимодальность** — скриншоты, изображения, диагностика UI
- **Roslyn-инструменты** — outline, references, callers, diagnostics без полной сборки
- **Встроенный браузер** — WebView2 для веб-интеракций
- **Оркестрация** — изолированные агенты с собственными скоупами

## Требования

- **.NET 10 SDK** (10.0.400+)
- **Windows 10/11** (WPF, WebView2)
- **Git** (лаунчер и самосборка работают через git CLI)
- **LLM-сервер** — OpenAI-совместимый API (llama.cpp или любой другой)
- **ffmpeg** — опционально, для мультимодальных задач (скачивается лаунчером)

## Быстрый старт

### 1. Клонировать (или форкнуть)

```bash
git clone https://github.com/Krokozor/QwenPlayground.git
cd QwenPlayground
```

### 2. Bootstrap (одноразово)

Запустите `bootstrap.bat` в корне проекта. Он:

- проверяет окружение (.NET 10 SDK, git)
- собирает лаунчер и watchdog в `launcher/`
- собирает первую версию приложения в `run/first` и активирует её
- создаёт ярлык `QwenPlayground.lnk` в корне

Повторный запуск безопасен: активная версия не затрагивается, пересобирается только лаунчер.

### 3. Запустить

Двойной клик по ярлыку `QwenPlayground.lnk` (или `launcher/QwenPlayground.Launcher.exe`). В лаунчере:

- **Запустить** — старт активной версии приложения
- **Пересобрать** — сборка + тест-гейт + деплой новой версии в `run/<id>`
- **Pull** — обновление из вашего origin
- **ffmpeg** — «Скачать» / «Проверить обновления» (опционально)

После bootstrap эстафета у лаунчера: все последующие сборки и обновления делаются из его GUI.

### 4. Настроить

При первом запуске/сохранении настроек приложение само создаёт:

- `settings.json` — настройки (Endpoint LLM-сервера и параметры модели — в вкладке «Настройки»)
- `main-agent.md` — идентичность агента (нейтральная заглушка; **этот файл ваш**: опишите свою среду, модели, конвенции)
- `trajectory.md` — траектория/«северная звезда» (нейтральная заглушка; редактирует сам агент)

## Форк

- «Pull» лаунчера и git-статусы работают с вашим `origin` (репозиторий в настройках лаунчера подтягивается из `git remote get-url origin`, поле `repo` в `launcher.json` — пустое по умолчанию).
- Если хотите, чтобы `rebuild_self` пушил в ваш форк: в приложении «Настройки» → «Самосборка» включите «пуш в GitHub» и укажите URL форка в «куда пушить». **По умолчанию при ребилдах ничего никуда не пушится.**
- Персональные файлы (`main-agent.md`, `trajectory.md`, `settings.json`, сессии, память) не лежат в git — каждый владелец создаёт свои.

## Структура

```
QwenPlayground/
├── src/
│   ├── QwenPlayground.Core/    # Ядро: агент, инструменты, память, Roslyn, self-build
│   └── QwenPlayground.App/     # WPF-приложение: UI, чат, настройки, браузер
├── tools/
│   ├── QwenPlayground.Launcher/ # Лаунчер: запуск, сборка, GitHub sync, инструменты
│   ├── QwenPlayground.Watchdog/ # Страж процесса (нативные краши)
│   └── QwenPlayground.Harness/  # Тестовый harness (headless-агент)
├── tests/
│   ├── QwenPlayground.Core.Tests/
│   └── QwenPlayground.App.Tests/
├── bootstrap.bat               # Одноразовая настройка из чистого клона
├── launcher.json               # Конфиг лаунчера (репозиторий, инструменты)
├── run/                        # Развёрнутые версии приложения (создаётся)
├── launcher/                   # Собранный лаунчер (создаётся)
├── external/                   # Внешние инструменты, бинарники (создаётся)
├── sessions/                   # Сессии агента (создаётся)
├── memories/                   # Долговременная память (создаётся)
└── settings.json               # Настройки приложения (создаётся)
```

## Архитектура путей

```
launcher.json → QWENPLAYGROUND_ROOT (env) → SelfBuildPaths.WorkspaceRoot
                                                         ↓
                                               все инструменты (Roslyn, rebuild)
                                                         ↓
                                               AdditionalWorkspaces (внешние папки)
```

Лаунчер ставит `QWENPLAYGROUND_ROOT` при запуске приложения. Приложение всегда знает, где живёт (self-modification), но может работать и с другими папками.

Версии — неизменяемые каталоги `run/<id>`; активная версия — указатель `run/current.txt` (pointer-layout: на Windows каталог нельзя удалить/переименовать под живым процессом).
